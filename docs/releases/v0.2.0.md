# Rind v0.2.0

Rind is an explainable, undoable macOS uninstaller and cleaner: every leftover file comes with
a reason and a confidence, and everything goes to the Trash where History can put it back.
No account, no telemetry, no background daemon.

**English** · [中文](#中文)

## English

This release brings:

- **A DMG installer**: download `Rind-v0.2.0.dmg` below and drag Rind into Applications.
  Unsigned and not notarized — the first launch needs right-click → Open. macOS 14+,
  Apple Silicon.
- **Dark mode**: follow the system / light / dark, remembered across launches; the native
  title bar switches with it.
- **A remembered language**: the chosen UI language persists; `RIND_LANG` still overrides it.
- **README previews**: the repo front page now opens in English, with English screenshots;
  the [Chinese README](https://github.com/ahjdzx/rind/blob/main/README.zh-CN.md) uses Chinese
  screenshots. See the Preview section of the
  [repo README](https://github.com/ahjdzx/rind#readme).

The GUI and the CLI share the same judgement. The safety model, protected areas and known
limits live in [docs/SAFETY.md](https://github.com/ahjdzx/rind/blob/main/docs/SAFETY.md)
(Chinese); the full change list is in
[CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md).

## 中文

Rind 是 macOS 上的卸载与清理工具：卸载时逐个文件说明「为什么属于这个 App、有多大把握」，
所有删除只进废纸篓，History 一键放回。没有账号、没有遥测、没有常驻进程。

这个版本带来：

- **DMG 安装包**：下载下面的 `Rind-v0.2.0.dmg`，把 Rind 拖进「应用程序」即可。
  未签名、未公证——第一次打开需要右键 →「打开」。macOS 14+，Apple Silicon。
- **深色模式**：外观可选跟随系统 / 浅色 / 深色，选择会记住；强制某一档时原生标题栏一起切换。
- **语言会记住**：设置里选中 / 英会落盘，下次启动沿用；`RIND_LANG` 环境变量仍可覆盖。
- **README 预览**：仓库首页现在是英文版，配英文截图；
  [中文 README](https://github.com/ahjdzx/rind/blob/main/README.zh-CN.md) 配中文截图。
  动图见 [仓库首页](https://github.com/ahjdzx/rind#readme) 的 Preview 一节。

界面与命令行用同一套判断；安全模型、保护区和已知边界见
[docs/SAFETY.md](https://github.com/ahjdzx/rind/blob/main/docs/SAFETY.md)，
完整改动见 [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md)。
