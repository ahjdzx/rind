# Rind v0.2.1

Rind is an explainable, undoable macOS uninstaller and cleaner: every leftover file comes with
a reason and a confidence, and everything goes to the Trash where History can put it back.
No account, no telemetry, no background daemon.

**English** · [中文](#中文)

## English

This release brings:

- **An app icon**: Rind now shows its own icon (a yellow rounded tile with an R) in the Dock,
  Finder and Launchpad instead of the blank generic one. It follows the macOS icon grid, so it
  sits at the same size as system apps.
- **The same logo inside the app**: the sidebar header uses it, and Settings gains an **About**
  card with the version and a one-line description.
- **English documentation**: the manual, the safety model and the design document are now
  available in English under [docs/en](https://github.com/ahjdzx/rind/tree/main/docs/en).

Install: download `Rind-v0.2.1.dmg` below and drag Rind into Applications. It is unsigned and
not notarized, so the first launch needs right-click → Open. macOS 14+, Apple Silicon.
The full change list is in [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md).

## 中文

Rind 是 macOS 上的卸载与清理工具：卸载时逐个文件说明「为什么属于这个 App、有多大把握」，
所有删除只进废纸篓，History 一键放回。没有账号、没有遥测、没有常驻进程。

这个版本带来：

- **应用图标**：Dock、Finder、启动台里显示 Rind 自己的图标（黄底圆角方格 + R），不再是空白图标；
  按 macOS 图标网格留边，和系统 App 一样大。
- **界面里也用同一个标志**：侧栏顶部换成它；设置页新增「关于」，显示版本号和一句介绍。
- **英文文档**：使用手册、安全模型、设计文档有了英文版，在
  [docs/en](https://github.com/ahjdzx/rind/tree/main/docs/en)。

安装：下载下面的 `Rind-v0.2.1.dmg`，把 Rind 拖进「应用程序」。未签名、未公证，第一次打开需要右键 →「打开」。
macOS 14+，Apple Silicon。完整改动见 [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md)。
