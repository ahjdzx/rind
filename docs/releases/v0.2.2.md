# Rind v0.2.2

Rind is an explainable, undoable macOS uninstaller and cleaner: every leftover file comes with
a reason and a confidence, and everything goes to the Trash where History can put it back.
No account, no telemetry, no background daemon.

**English** · [中文](#中文)

## English

A fix release:

- **No more blank icons**: 15 icons in the interface rendered as empty squares — the sidebar
  entries for Uninstall apps / Orphaned files / Caches & junk / Launch items, the cards on the
  Overview, the Smart scan button, close buttons and more. They are all drawn now, and a test
  fails if a newly used icon is ever left unregistered.
- **Fresh screenshots**: the README previews and `demo.gif` (English and Chinese) were
  re-captured from this build.

Install: download `Rind-v0.2.2.dmg` below and drag Rind into Applications. It is unsigned and
not notarized, so the first launch needs right-click → Open. macOS 14+, Apple Silicon.
The full change list is in [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md).

## 中文
