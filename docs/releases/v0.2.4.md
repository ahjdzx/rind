# Rind v0.2.4

Rind is an explainable, undoable macOS uninstaller and cleaner: every leftover file comes with
a reason and a confidence, and everything goes to the Trash where History can put it back.
No account, no telemetry, no background daemon.

**English** · [中文](#中文)

## English

A safety and engineering hardening release:

- **Signing evidence is trusted, not claimed**: Team IDs and App Groups are only used for
  matching after `codesign` verifies the signature chain to Apple. A forged signing claim can
  no longer influence leftover attribution.
- **Dry runs match real runs**: uninstall rehearsals run the same descendant check for photo /
  music libraries and wallet-bearing browser profiles, so a path shown as moveable can no
  longer be refused on the real run.
- **Safer cleanup**: dev artifacts are held back while processes such as `vite`, `esbuild`, or
  build tools are running from them. Unknown process lists fail closed.
- **Better CLI behavior**: early closed pipes exit quietly instead of panicking; scan progress
  stops writing ANSI escapes into logs; and empty / cancelled operations return exit code 3
  instead of colliding with argument errors.
- **Release pipeline checks**: CI enforces the real Rust 1.89 MSRV and locked builds; releases
  run workspace clippy and tests before producing a DMG.

Install: download `Rind-v0.2.4.dmg` below and drag Rind into Applications. It is unsigned and
not notarized, so the first launch needs right-click → Open. macOS 14+, Apple Silicon.
The full change list is in [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md).

## 中文

一次安全与工程加固版本：

- **签名证据要验证，不只看声明**：Team ID 和 App Group 现在只有在 `codesign` 验证签名链到
  Apple 后才用于匹配。伪造签名内容不能再影响残留归属。
- **预演和真跑一致**：卸载预演也会做同样的子孙探测，包含照片 / 音乐库或钱包 profile 的目录
  在预演里就拒绝，不再出现「预演说能动、真跑拒绝」。
- **清理更稳**：`vite`、`esbuild` 或构建工具正在使用开发产物时，对应项会被挡住；进程列表
  读不到时按不能确认处理。
- **命令行体验修复**：管道提前关闭不再 panic；扫描进度不再把 ANSI 控制字符写进日志；
  空结果 / 用户取消的退出码改成 3，不和参数错误混淆。
- **发版流程校验**：CI 固定真实的 Rust 1.89 MSRV 并使用锁定依赖；Release 会先跑整个工作区的
  clippy 和测试，再打 DMG。

安装：下载下面的 `Rind-v0.2.4.dmg`，把 Rind 拖进「应用程序」。未签名、未公证，第一次打开需要
右键 →「打开」。macOS 14+，Apple Silicon。完整改动见
[CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md)。
