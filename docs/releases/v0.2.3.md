# Rind v0.2.3

Rind is an explainable, undoable macOS uninstaller and cleaner: every leftover file comes with
a reason and a confidence, and everything goes to the Trash where History can put it back.
No account, no telemetry, no background daemon.

**English** · [中文](#中文)

## English

A small wording and layout release:

- **Clearer "needs admin" notes**: items that need administrator rights now say
  "Needs admin rights; listed, never moved" instead of "left alone for now". Rind deliberately
  never asks for elevation, so these are not a to-do; the CLI's launch-item message drops
  "this version" for the same reason.
- **Full reasons on Launch items**: when an item can't be managed, its reason now wraps onto a
  second line instead of being cut off with an ellipsis.

Install: download `Rind-v0.2.3.dmg` below and drag Rind into Applications. It is unsigned and
not notarized, so the first launch needs right-click → Open. macOS 14+, Apple Silicon.
The full change list is in [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md).

## 中文

一个文案与布局的小版本：

- **「需要管理员权限」说清楚**：这类项现在显示「需要管理员权限，只列出、不移动」，不再写「这一版先不动它」。
  Rind 有意不申请提权，这不是待办；命令行里启动项的提示也去掉了「这一版」。
- **启动项的原因完整显示**：不能操作的项，原因放不下时换行，不再被省略号截掉。

安装：下载下面的 `Rind-v0.2.3.dmg`，把 Rind 拖进「应用程序」。未签名、未公证，第一次打开需要右键 →「打开」。
macOS 14+，Apple Silicon。完整改动见 [CHANGELOG.md](https://github.com/ahjdzx/rind/blob/main/CHANGELOG.md)。
